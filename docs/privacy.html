Kumquat

Privacy Policy

Last updated: October 18, 2026 · Español

Kumquat is a free, open-source macOS app. This policy explains what happens with your data when you use the app and this website. In short: your files never leave your Mac, and Kumquat collects nothing about you.

Your files

Every conversion and tool (including background removal and text recognition) runs locally on your Mac using Apple's frameworks, the tools macOS ships with, and optional engines you installed yourself (FFmpeg, LibreOffice, Ghostscript, WebP). Files are never uploaded anywhere. Results are saved where you choose in Settings.

What Kumquat does not do

  • No accounts, sign-ups or logins.
  • No analytics, telemetry, crash reporting, advertising or tracking.
  • No reading of your screen, keystrokes or clipboard. Kumquat watches the system drag pasteboard and modifier keys only to know when to show its ring, and puts recognized text on the clipboard only when you use Get Text.

The one network request: update checks

If "Check for updates automatically" is on (Settings → About), Kumquat asks GitHub's public API for the latest release version a few seconds after launch and then every few hours. The request contains no personal data, but like any web request it reaches GitHub from your IP address and is subject to GitHub's Privacy Statement. You can turn it off at any time. Updating, when you choose to, downloads the new version from GitHub.

Permissions

The ⌃⌥K shortcut asks macOS once for permission to read which files are selected in Finder. Kumquat uses it for nothing else. No Accessibility or Screen Recording permission is required.

Settings stored on your Mac

Your preferences and a short list of recent results are stored locally in macOS user defaults. You can remove them with defaults delete io.github.iandifilippo.kumquat.

This website

This site is hosted on GitHub Pages. It uses no cookies, analytics or trackers; it only remembers your language choice in your browser's local storage. GitHub may keep standard server logs as described in its Privacy Statement. Fonts are loaded from Google Fonts.

Children

Kumquat collects no personal information from anyone, including children.

Changes and contact

If this policy changes, the new version will be published here with a new date. Questions: open an issue at github.com/iandifilippo/Kumquat/issues.

Política de privacidad

Última actualización: 18 de octubre de 2026

Kumquat es una app gratuita y de código abierto para macOS. Tus archivos nunca salen de tu Mac y Kumquat no recopila nada sobre ti.

  • Archivos: todas las conversiones y herramientas (incluidos quitar fondo y reconocer texto) se hacen en tu Mac. Nada se sube a internet.
  • Sin cuentas, analíticas, publicidad ni rastreo. Kumquat no lee tu pantalla ni lo que escribes; solo observa el arrastre del sistema y las teclas modificadoras para mostrar el anillo.
  • Única conexión: si la búsqueda automática de actualizaciones está activada, Kumquat pregunta a la API pública de GitHub por la última versión. No envía datos personales; se rige por la declaración de privacidad de GitHub. Puedes desactivarla en Ajustes → Acerca de.
  • Permisos: el atajo ⌃⌥K pide una vez permiso para leer la selección de Finder. No hace falta Accesibilidad ni Grabación de pantalla.
  • Ajustes: se guardan solo en tu Mac.
  • Este sitio: alojado en GitHub Pages, sin cookies ni analíticas; solo recuerda tu idioma en tu navegador.

Dudas: github.com/iandifilippo/Kumquat/issues.
